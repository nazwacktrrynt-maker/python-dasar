# Python Dasar

Repositori praktikum Python Dasar berdasarkan tutorial Santrikoding (19 bab).
Setiap bab dikerjakan dan di-commit secara terpisah, lengkap dengan screenshot hasil eksekusi di folder `screenshots/`.

## Rangkuman Materi

- Bab 1-2: Pengenalan, instalasi, dan struktur dasar program Python
- Bab 3-5: Tipe data, variable, dan konstanta
- Bab 6-7: Operator dan control flow (if, for, while)
- Bab 8: Function
- Bab 9-10: List, tuple, set, dan dictionary
- Bab 11-15: OOP (class, encapsulation, inheritance, polymorphism, abstraction)
- Bab 16-17: Exception handling dan file handling
- Bab 18-19: Module dan package

## Cara Menjalankan

```
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
python bab01_pengenalan.py
```
